# Story TTS API

API backend để website truyện tạo audio tiếng Việt theo yêu cầu bằng Edge-TTS.

- Giọng: Nam Minh, Hoài My
- Tốc độ: 0.75x, 1x, 1.25x, 1.5x, 2x
- API key phía máy chủ, hàng đợi tổng hợp, cache MP3 theo nội dung + giọng + tốc độ.
- Website gửi nội dung chương; API không tự quét URL hoặc vượt cơ chế đăng nhập/paywall.

Xem tài liệu tích hợp và triển khai trong README đầy đủ sẽ được cập nhật tiếp.
